# Этап 4 — Хранилище: IndexedDB, экспорт/импорт JSON

**Статус:** ждёт этап 2 (модель теста) **Покрывает:** раздел 2 (хранилище), п. 3 (схема), п. 7.5 (история прогонов) спецификации

## Цель

Тесты не живут в памяти панели: сохранение в IndexedDB, история прогонов, перенос между машинами через JSON-файл.

## Входит

1. **Схема IndexedDB** (библиотека `idb` или чистый API, одна БД `qa-recorder`):
   - `tests` — keyPath `test_id`; документ по схеме п. 3 (с `resolution`/`action`, `frame_path`, normalized-текстами);
   - `runs` — keyPath `run_id`, индекс по `test_id` + `started_at`; на шаг: сработавший кандидат, время резолва, фаза, результат;
   - `screenshots` — blob-ссылки (схема закладывается сейчас, наполняется на этапе 5e).
2. **CRUD тестов** в панели: список тестов, открыть, переименовать, удалить, дублировать.
3. **Экспорт:** выгрузка выбранного теста (или всех) в JSON-файл, версия формата в корне (`"format_version": "0.2"`).
4. **Импорт:** загрузка JSON, валидация по схеме, конфликт `test_id` → предложение «заменить / импортировать копией».
5. **Сохранение прогонов (п. 7.5):** по завершении плеера (этап 3) запись в `runs`; просмотр последнего прогона из карточки теста.
6. **Миграция формата:** чтение `format_version`, явная ошибка на неподдерживаемую версию (миграции — по мере появления версий).

## Не входит

- Тренды по истории прогонов (раздел 10 спеки) — будущая версия.
- Синхронизация между машинами (только ручной экспорт/импорт).

## Критерии приёмки

1. Тест переживает закрытие браузера и открывается из списка.
2. Экспорт → удаление теста → импорт = побайтово эквивалентный тест (по JSON).
3. Импорт файла с битой схемой → понятная ошибка, БД не тронута.
4. После прогона в `runs` появляется запись с результатами всех шагов.
5. Импорт файла с существующим `test_id` → диалог выбора, оба пути работают.

## Риски

- Квота IndexedDB на скриншоты (этап 5e) → уже сейчас хранить blob отдельно от документа теста, по ссылке.
- Background SW в MV3 выгружается — все операции записи делать короткими транзакциями, без «открытой» БД в фоне.
