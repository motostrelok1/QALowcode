# Этап 5b — Цепочки: многоуровневые меню и слэш-команды

**Статус:** ждёт этапы 1–3 **Покрывает:** п. 6.3, 7.2e, 8.4, раздел 9 спецификации

## Цель

Запись и воспроизведение цепочек «триггер → выпавший контейнер → действие внутри него»: многоуровневые меню, каскадные дропдауны, слэш-меню.

## Входит

1. **Запись (п. 6.3):**
   - `MutationObserver` на время записи: снимок DOM до события, фиксация новых контейнеров после;
   - «окно ожидания» (2–3 с бездействия): следующее событие внутри нового контейнера → общий `group_id` цепочке;
   - идентификация контейнера: `aria-controls`/`aria-expanded`, связь id триггера → id контейнера, fallback «первый новый узел рядом с триггером»;
   - шаги цепочки получают `within` = селектор контейнера.
2. **Воспроизведение (п. 7.2e, раздел 9):**
   - перед каждым шагом группы — проверка, что контейнер в DOM;
   - контейнер исчез → перезапуск группы с её первого шага (лимит: 2 перезапуска, потом провал группы);
   - действия внутри группы без побочных промежуточных событий; настраиваемая пауза между наведением на родительский и дочерний пункт.
3. **UI (п. 8.4):** сворачивание группы в одну строку; авторазворот при провале/ре-резолве внутри.

## Не входит

- Слэш-меню *внутри contenteditable* — этап 5c (там своя механика ввода `/`).
- Эвристика «меню» сверх MutationObserver (например, по `role="menu"`) — только если практика покажет пропуски.

## Критерии приёмки

1. Двухуровневое меню (hover → подменю → клик) записывается одной группой с общим `group_id`.
2. Воспроизведение проходит цепочку; при принудительном закрытии меню между шагами группа перезапускается и доходит до конца.
3. Клик «мимо» при записи вне окна ожидания не попадает в группу.
4. В списке шагов группа сворачивается/разворачивается, провал внутри разворачивает её автоматически.

## Риски

- Приложение пересоздаёт контейнер при каждом открытии → селектор контейнера должен быть таким же кандидатным (иерархия п. 4), иначе `within` протухает.
- Длинные анимации открытия → опрос кандидатов каждые 100 мс (этап 3) покрывает, но пауза между уровнями должна быть настраиваемой.
